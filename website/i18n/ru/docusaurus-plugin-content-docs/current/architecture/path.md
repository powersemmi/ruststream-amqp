# Путь

Путь одной доставки AMQP 1.0 через сервис RustStream: задача приёма, канал, обработчик, ответ и
диспозиция.

<Diagram name="path" words={words} />

Задача приёма подписки владеет её принимающей связью. Для приёма связь нужна ей целиком, а
урегулирование связь только читает. При этом доставку, которую держит обработчик, нужно передавать
между задачами. Поэтому принимает задача приёма, и каждое урегулирование возвращается к ней
командой. Ответ клиента приходит обработчику через слот, который подписка использует повторно,
поэтому урегулирование не выделяет память.

Задача приёма превращает передачу в [`AmqpMessage`](api:ruststream_amqp::AmqpMessage). Заголовки
берутся из секций `properties` и `application-properties`, байты - из секции `data`, а
`delivery-count` - из секции `header`. Секция значения со строкой или двоичными данными тоже
читается как байты, а доставка с любым другим телом отклоняется, и подписка получает ошибку. Затем
задача приёма кладёт доставку в канал глубиной в [кредит связи](../components/subscriptions/credit.md) и, пока ждёт в нём места, выполняет
команды урегулирования.

Доставка, которую клиент не может прочитать, например доставка больше, чем допускает связь,
передаётся подписке как ошибка, а связь остаётся присоединённой. Если брокер отправляет передачи сверх
выданного ему кредита, связь разрывается, и подписка заканчивается.

Ответ обработчика кодируется в буфер, который цикл диспетчеризации использует повторно. Издатель
[`AmqpPublisher`](../components/publishing/index.md) берёт этот буфер как секцию `data`
сообщения, без копирования. Он отправляет сообщение неурегулированным по отправляющей связи адреса и держит
связь, пока не придёт диспозиция брокера. Поэтому публикации в один адрес с одного соединения
уходят по одной, и каждая стоит одного кругового обмена. Диспозиция с исходом, отличным от
`accepted`, - это [ошибка](../components/broker/errors.md). Если ответ не удалось опубликовать, доставка урегулируется повтором.

Доставка урегулируется после ответа. Её исход становится диспозицией, как показывает страница
[Урегулирование](settlement.md).
